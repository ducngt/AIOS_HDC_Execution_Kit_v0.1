# AIOS Engineering Invariants

1. AIOS = AI Operating System.
2. Human owns Purpose, Meaning, Authority, Responsibility and Acceptance.
3. AI performs software engineering under Human review.
4. Capability != Authority.
5. Authority != Competence.
6. Signature != Authority.
7. Authentication != Signature.
8. Multiple roles != union of authority.
9. Management role drives default dashboard only; action permission remains context-bound.
10. Organization is data, not software structure.
11. Stable capability; configurable organization.
12. Domain may extend Core; domain must not redefine Core.
13. One Semantic Reality; many physical stores.
14. Current state may change; history must remain traceable.
15. AI working data != institutional data.
16. Inference != Fact; Recommendation != Decision; Prediction != Evidence.
17. No connection without contract.
18. No cross-domain direct DB access.
19. Reuse existing capability before creating new capability.
20. No single Super Agent.
21. Model is replaceable; University Memory persists.
22. GitHub is engineering source/provenance, not authoritative operational data store.
23. Main branch represents accepted engineering state.
24. Built != Activated.
25. Temporary scratch may disappear; institutionally meaningful failure remains traceable.
